Created a deep learning brain tumor classification model. The model can classify four different labels: glioma, meningioma, pituitary and no tumor.
Grad-CAM is used to highlight the tumor's location. The model weights are saved and uploaded to Hugging Face. The training file is uploaded 
to GitHub; anyone can use it as needed.

Dataset link: https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset 
Trained weights: https://huggingface.co/Henishma/brain_tumor_classification
